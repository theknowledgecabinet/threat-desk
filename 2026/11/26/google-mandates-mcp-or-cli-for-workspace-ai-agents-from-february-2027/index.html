Google mandates MCP or CLI for Workspace AI agents from February 2027

Google is restricting how autonomous AI agents access Workspace data, requiring them to use new Model Context Protocol servers or a command-line interface to enforce security controls.

Google has announced that, from 1 February 2027, AI agents must connect to Google Workspace via its new Model Context Protocol (MCP) servers or the Workspace command-line interface (CLI). The company stated that traditional REST APIs, designed for human-paced applications, are insufficient for autonomous agents operating at machine speed, necessitating built-in security checks and data access restrictions.

The MCP servers support Gmail, Google Drive, Docs, Sheets, Slides, Calendar, Chat, and Tasks, with Google Keep support planned. These interfaces enforce organisational permissions, data loss prevention (DLP) policies, and classification labels. Additionally, the servers require human confirmation for sensitive operations, such as sending emails or modifying sharing permissions, and reject non-agent OAuth clients.

For Google Cloud, agents will receive individual identities through the Agent Registry, governed by identity and access management (IAM) policies. The new Google Cloud Agent Gateway will verify agent identities, enforce default-deny outbound rules, and use the Model Armor service to screen requests for prompt injection. The Workspace AI Tools Addendum also prohibits the permanent storage of raw Workspace data for model training and sets a 30-day retention limit for certain technical information.

Affected

Google Workspace, Google Cloud

Actions

  • Migrate agent integrations to Workspace MCP servers or the CLI before the February 2027 enforcement deadline.
  • Review connected applications and agents in the admin console to ensure compliance with the new AI Tools Addendum.
  • Configure DLP policies and monitor OAuth activity logs to track agent behaviour.
  • Implement user confirmation and prompt injection protection mechanisms in agent workflows.
