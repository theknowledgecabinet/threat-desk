Roundcube Webmail patches 12 flaws in 1.6.22 and 1.7.7

Roundcube released updates on 23 November 2026 to fix 12 security vulnerabilities, including issues with attachment handling and unencrypted connections.

Roundcube released versions 1.6.22 and 1.7.7 on 23 November 2026 to address 12 security flaws in its browser-based email client. The updates fix weaknesses in how the software handles attachments, displays messages, and connects to mail servers. The release notes describe flaws that could expose data and allow unauthorised email filter code to run, but they do not confirm remote code execution on the webmail server or report active exploitation of these bugs.

One fix stops Roundcube from passing unsafe PDF, PostScript, and SVG attachment content to ImageMagick, a tool used to process images. The project also revisited an HTTP request injection flaw in its ATD spellcheck backend. Several other fixes address how Roundcube displays HTML email, including two flaws that let message styling break out of limits meant to keep it separate from the webmail interface, and another that let SVG content load external resources despite user remote-content settings.

The update also closes a flaw that could expose responses handled by the CSS proxy and fixes a gap in the HTML filter on systems running PHP versions earlier than 8.4. Two separate flaws could let unauthorised instructions enter Sieve scripts, while another fix addresses XML injection in the XIMSS driver of Roundcube’s password plugin. The release also closes a denial-of-service flaw where the decoder for TNEF attachments could spend too long processing attachment data.

The updates stop Roundcube from falling back to unencrypted IMAP, SMTP, or ManageSieve connections when TLS encryption is configured, even if the mail server does not advertise the required capability. The official Roundcube 1.6.22 release notes identify it as the final release in the 1.6 long-term support branch. Roundcube says only the 1.7 branch will receive future security updates.

Affected

Roundcube Webmail versions prior to 1.6.22 and 1.7.7

Actions

  • Update to Roundcube Webmail 1.6.22 or 1.7.7 immediately.
  • Back up data before applying the patch to production systems.
  • Migrate from the 1.6 branch to 1.7 to ensure access to future security updates.
