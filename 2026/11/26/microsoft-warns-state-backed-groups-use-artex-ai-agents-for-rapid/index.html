Microsoft warns state-backed groups use ARTEX AI agents for rapid intrusions

Microsoft identified six threat actors, including Storm-0940, using the ARTEX framework to automate credential theft and privileged access in cloud environments.

In a report published on 25 November, Microsoft warned that state-backed and financially motivated groups are abusing ARTEX, an AI-powered penetration testing framework, to accelerate intrusions. The framework uses AI agents to move from scanning to persistent, privileged access within minutes, reducing the need for manual operator intervention between steps.

Microsoft Threat Intelligence researchers identified six threat actors using ARTEX: Storm-0940, Storm-3358, Onyx Sleet, Pearl Sleet, Crystal Typhoon, and Salt Typhoon. In one instance, an agent extracted data from Azure Key Vault in five minutes after finding secrets in public GitHub repositories. Microsoft’s investigation into the ConnectWise supply chain campaign found that China-aligned Storm-0940 used ARTEX to accelerate intrusions. In multiple Storm-0940 intrusions, Microsoft observed the group reach privileged cloud access less than three hours after initial targeting, recording over 151,000 failed sign-ins in one campaign.

Defenders should look for sequences of events rather than single indicators, such as bursts of web requests followed by successful access or unusual server processes. Microsoft recommends patching exposed systems, using web application firewalls in prevention mode, and enabling secret scanning to catch credentials before they enter repositories.

Actions

  • Enable secret scanning and push protection to prevent credentials from entering repositories.
  • Require phishing-resistant multifactor authentication for administrators.
  • Enable automatic attack disruption in Defender XDR to contain compromised assets.
