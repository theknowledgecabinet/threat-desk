Adobe patches critical flaws in Experience Manager and Campaign Classic

Adobe released updates on 24 November 2026 to fix critical vulnerabilities in Experience Manager and Campaign Classic that allow code execution and privilege escalation.

Adobe published security bulletins APSB26-104 and APSB26-194 on 24 November 2026, addressing critical vulnerabilities in Adobe Experience Manager and Adobe Campaign Classic. The updates fix flaws with CVSS 3.1 scores of up to 9.9, including code injection and SQL injection issues that could allow attackers to execute malicious code or gain unauthorized access. Adobe stated it was not aware of any attacks using these flaws at the time of publication, and CISA does not list them as known exploited.

For Experience Manager, the critical code injection vulnerabilities CVE-2026-123266 and CVE-2026-132877 allow a low-privileged attacker to execute arbitrary code without user interaction. The affected versions include Experience Manager Cloud Service 2026.10.29251 and earlier, Experience Manager 6.5 Service Pack 26 and earlier, and Experience Manager 6.5 LTS Service Pack 3 and earlier. Adobe provides cumulative hotfixes for specific service packs and a fixed cloud release, 2026.11.29643.

The Campaign Classic bulletin covers 12 critical flaws in on-premises deployments on Windows and Linux. These include code injection, SQL injection, and authorisation flaws. Organisations running Campaign Classic 7.4.4 build 9403 or earlier must move to build 9404, while those on 7.4.5 build 9420 or earlier should move to build 9421. Administrators are advised to verify the specific build number, as patched and affected servers may report the same version number.

Affected

Adobe Experience Manager Cloud Service 2026.10.29251 and earlier; Experience Manager 6.5 Service Pack 26 and earlier; Experience Manager 6.5 LTS Service Pack 3 and earlier; Campaign Classic 7.4.4 build 9403 or earlier; Campaign Classic 7.4.5 build 9420 or earlier

Actions

  • Apply the relevant Adobe Experience Manager hotfix or update to cloud release 2026.11.29643.
  • Update Adobe Campaign Classic to build 9404 (for 7.4.4) or build 9421 (for 7.4.5).
  • Verify the specific build number on each server to confirm the patch is installed, as version numbers alone may be ambiguous.
