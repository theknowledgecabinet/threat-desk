Fake WordPress plugin bypasses 2FA and serves malicious scripts

Wordfence identified a hidden plugin that creates valid login sessions without 2FA and relays attacker-controlled JavaScript to visitors.

Researchers from the Wordfence Threat Intelligence Team identified a fake WordPress plugin during incident response investigations in January and September 2026. The malware hides from the WordPress dashboard and uses generated names, stylesheets, and configuration files to appear legitimate. Approximately two-thirds of the plugin files consist of filler, with the active malware contained in PHP and JavaScript components.

The plugin contains a backdoor that creates a valid WordPress login session for an existing account, bypassing standard password and two-factor authentication checks. Changing an administrator’s password does not invalidate this access while the malicious code remains active. Additionally, the plugin manipulates file timestamps to match existing plugins, making detection via recently modified files difficult.

For non-logged-in visitors, the plugin relays JavaScript from an attacker-controlled server through the infected site. This obfuscates the traffic source, making it appear as if the script originated from the legitimate website. Wordfence stated the loader could support phishing forms, fake update prompts, malicious redirects, or keystroke logging, though these are potential uses rather than confirmed outcomes in the observed incidents.

Affected

WordPress sites

Actions

  • Compare plugins listed in the dashboard with files under wp-content/plugins/ to identify hidden installations.
  • Check the public site while signed out in a separate browser profile to detect visitor-facing malicious behaviour.
  • Remove the plugin, investigate installation vectors, and rotate credentials for administrator accounts.
  • Revoke existing sessions and review active sessions after cleanup to ensure no other implants remain.
