Unit 42 tracks AI agents accelerating corporate intrusions

Researchers identified autonomous AI agents used to expand access in over 10 campaigns, reducing command intervals from 23.9 seconds to 1.4 seconds.

Palo Alto Networks’ Unit 42 published a research report on 24 November 2026 stating that attackers used autonomous AI agents to steal credentials and probe cloud systems in more than 10 campaigns tracked between July and September 2026. The activity targeted government, logistics, hospitality, manufacturing, agriculture, and education organisations.

The most successful intrusions combined human direction with autonomous execution, where a person provided initial access while the agent mapped systems and attempted to expand privileges. In one case, an agent ran approximately 800 unique commands over 140 minutes, surveying websites, databases, and cloud environments. Unit 42 noted that the median gap between commands fell from 23.9 seconds during manual activity to 1.4 seconds after an AI agent took over.

Researchers recovered hundreds of unique script payloads, including PHP web shells and Python credential harvesters, but found no compiled backdoor or single shared malware family. In one instance, an agent used stolen file-sharing credentials to move from a Linux server to a Windows server running Internet Information Services (IIS), where web shells were found in more than 40 locations.

Affected

Linux servers, Windows servers running Internet Information Services (IIS), Amazon Web Services, self-managed GitLab instances

Actions

  • Patch internet-facing applications and review where web servers can connect inside the network.
  • Check whether Linux kernel security updates are active on affected hosts to mitigate Copy Fail privilege escalation attempts.
  • If a web shell is found, isolate the server, preserve relevant logs, and revoke or rotate credentials it could access.
  • Implement multifactor authentication, sign-in rate limits, and IP restrictions for self-managed GitLab instances.
