North Korea-linked PolinRider poisons 7,600 GitHub repos

SafeDep reports that threat actors linked to North Korea have compromised over 7,600 GitHub repositories to distribute malware via a Python loader.

SafeDep has identified a campaign dubbed PolinRider, in which threat actors linked to North Korea have planted a Python loader in GitHub repositories. The firm stated that evidence suggests the activity may have begun as far back as February 2025.

According to SafeDep, the loader is concealed within a small utils package or in conftest.py files. When Python imports the file, the loader reads the newest transaction. The report indicates that more than 7,600 repositories have been affected by this supply chain poisoning.

Affected

GitHub repositories containing Python utils packages or conftest.py files

Actions

  • Audit Python dependencies for unexpected utils packages or conftest.py files.
  • Review recent commits in Python projects for suspicious loader code.
  • Verify the integrity of third-party Python packages before deployment.
