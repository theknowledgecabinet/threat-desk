WHMCS SQL injection flaw exposes customer data and admin hashes

An unauthenticated SQL injection vulnerability in WHMCS allows attackers to retrieve customer records and administrator password hashes from the platform's database.

WHMCS has disclosed a SQL injection vulnerability in its shopping cart component, which is widely used by web hosting companies for billing and automation. The flaw permits any user on the internet to access the installation's database without requiring a login.

According to The Hacker News, the vulnerability could allow the retrieval of customer records and administrator password hashes. The company disclosed this issue alongside two other flaws that require a logged-in client to exploit.

Security professionals should note that while the primary flaw is unauthenticated, the other two disclosed vulnerabilities require valid client credentials. Organisations using WHMCS should verify their patch status immediately to prevent data exfiltration.

Affected

WHMCS (specific versions not listed in source)

Actions

  • Audit database access logs for unauthenticated queries.
  • Rotate administrator credentials if exposure is suspected.
