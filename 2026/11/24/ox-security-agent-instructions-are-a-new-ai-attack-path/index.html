Ox Security: Agent instructions are a new AI attack path

Analysis of 542,207 components shows prompt injection and tool poisoning are prevalent in MCP servers and agent skills, bypassing traditional code-based security checks.

Ox Security has warned that threat actors are hijacking AI agents through instructions rather than malicious code. The vendor’s 'Plug and Pray' report, based on an analysis of 542,207 open source components between July and October 2026, found that prompt injection and tool poisoning are more prevalent in certain ecosystems than traditional malware.

In Model Context Protocol (MCP) servers, 22% of flagged components contained prompt injection or tool poisoning, while 16% executed code at install or import time. In agent skills, the disparity was wider: 26% contained such techniques, compared to 0% with install-time execution. Additionally, 44% of agent skills contained instructions directing agents to exfiltrate data. Neatsun Ziv, CEO of Ox Security, stated that companies are relying on trust signals built for a different era, noting that the issue is who controls the tool and what instructions it gives the agent.

The report highlights that traditional software trust models are failing. Ox Security found a source owner for only 70% of MCP servers, compared to 93% of npm packages. Furthermore, 67% of MCP servers ran on publisher-controlled infrastructure, making independent code verification impossible, and 82% were malicious in their first observed version, leaving no clean baseline for comparison.

Affected

MCP servers, agent skills, npm, PyPI

Actions

  • Verify who controls the tools your agents connect to and identify the publisher.
  • Confirm whether you can independently verify the code the tools run and if it matches publisher claims.
  • Implement monitoring to detect changes to tools running on external infrastructure.
