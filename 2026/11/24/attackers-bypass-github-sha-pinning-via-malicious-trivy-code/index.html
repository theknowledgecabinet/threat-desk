Attackers bypass GitHub SHA pinning via malicious Trivy code

Threat actors have demonstrated a method to circumvent SHA pinning in GitHub Actions by injecting malicious code into the Trivy scanner that mimics official checkout tools.

SHA pinning, the practice of pinning GitHub Actions to an exact version of their code, has become a standard defence against software supply chain attacks. However, attackers have identified a way to bypass this control. According to The Hacker News, this gap is the subject of a recent webinar explaining how to close the security hole.

In March 2026, the hackers who hijacked Trivy, a widely used open-source security scanner, planted malicious code designed to appear as if it originated from GitHub's official checkout tool. The source notes that the attackers even labelled the malicious component.

Affected

Trivy (open-source security scanner), GitHub Actions

Actions

  • Review GitHub Actions workflows for unexpected or mislabelled checkout actions.
  • Audit third-party tools like Trivy for signs of compromise or tampering.
  • Monitor for code that mimics official GitHub tools to detect supply chain manipulation.
