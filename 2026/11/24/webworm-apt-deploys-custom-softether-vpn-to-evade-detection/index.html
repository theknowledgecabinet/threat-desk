Webworm APT deploys custom SoftEther VPN to evade detection

Rapid7 identified a modified SoftEther VPN tool used by the China-aligned Webworm group to maintain stealthy access to government networks.

Rapid7 published research on 19 November 2026 detailing a custom tool used by Webworm, a China-aligned advanced persistent threat group active since at least 2017. The group, also tracked as Erudite Mogwai and Space Pirates, primarily targets government organisations in Europe. The new tool, internally named "NtMonitor", is a modified build of the open source SoftEther VPN Bridge compiled for Windows x64.

According to Rapid7 researcher Milan Spinka, the attackers methodically analysed SoftEther's detection surface to implement counter-measures. The tool strips out standard artifacts, changes metadata to refer to generic "Network Monitor Software", and renames internal strings, HTTP endpoints, and handshake watermarks. Additionally, the core file hamcore.se2 is embedded inside the executable, and the plaintext configuration file is renamed and encrypted with a custom cipher to evade standard detection signatures.

Rapid7 attributed the software to Webworm with moderate confidence based on alignment with previously reported tactics, techniques, and procedures, as well as remote IP addresses linked to past Webworm activity. The research includes indicators of compromise and YARA rules for defenders. One of Webworm's primary initial access methods appears to be exploiting vulnerabilities through external web-facing applications.

Affected

SoftEther VPN Bridge (Windows x64)

Actions

  • Prioritise patching for internet-facing applications
  • Enforce Web Application Firewall (WAF) controls
  • Implement strict network egress controls
  • Deploy YARA rules and IOCs provided by Rapid7
