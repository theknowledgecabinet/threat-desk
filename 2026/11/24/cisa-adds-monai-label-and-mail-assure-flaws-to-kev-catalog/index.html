CISA adds MONAI Label and Mail Assure flaws to KEV Catalog

CISA has added two critical vulnerabilities to its Known Exploited Vulnerabilities Catalog, citing active exploitation of a path traversal flaw in MONAI Label and an SSRF issue in N-able Mail Assure.

CVE-2026-133968CVE-2026-134624

CISA announced on 23 November 2026 that it has added two vulnerabilities to the Known Exploited Vulnerabilities (KEV) Catalog based on evidence of active exploitation. The first is CVE-2026-133968, a path traversal vulnerability in Project MONAI MONAI Label that allows remote code execution via the image parameter to the PUT /datastore/image endpoint. The NVD records indicate this flaw has been exploited in the wild since September 2026 and carries a CVSS 3.1 base score of 9.8 (critical).

The second addition is CVE-2026-134624, a server-side request forgery (SSRF) vulnerability in N-able Mail Assure (SpamExperts). According to the NVD, the software fails to restrict the destination of the LDAP synchronisation connection check when a relay is configured. An authenticated API user can exploit this to connect to arbitrary internal hosts and ports, determine reachability, and send crafted data to internal services. This vulnerability has a CVSS 4.0 base score of 9.3 (critical).

CISA stated that these types of vulnerabilities are frequent attack vectors for malicious cyber actors and pose significant risks to the federal enterprise. Under Binding Operational Directive 26-04, Federal Civilian Executive Branch agencies are required to prioritise rapid remediation of high-risk vulnerabilities listed in the KEV Catalog, particularly those on publicly exposed assets that grant total control post-exploitation. CISA encourages all organisations to adopt risk-based vulnerability management and prioritise remediation of KEV Catalog vulnerabilities.

Affected

Project MONAI MONAI Label before 0.8.6; N-able Mail Assure (SpamExperts) before 20261121.1943

Actions

  • Upgrade MONAI Label to version 0.8.6 or later to remediate CVE-2026-133968.
  • Update N-able Mail Assure (SpamExperts) to version 20261121.1943 or later to fix CVE-2026-134624.
  • Prioritise remediation of these vulnerabilities on publicly exposed assets in accordance with CISA guidance.
  • Check for signs of compromise on systems affected by these vulnerabilities before applying patches.
