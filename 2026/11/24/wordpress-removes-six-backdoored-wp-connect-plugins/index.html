WordPress removes six backdoored WP Connect plugins

WordPress blocked six malicious plugin releases from WP Connect after a suspected developer account compromise enabled arbitrary code execution.

WordPress has removed six plugins developed by WP Connect following a suspected compromise of the developer's account on 22 November 2026. The compromised account was used to inject backdoors into the plugins, which would have enabled arbitrary code execution on any site with them installed.

The WordPress plugins team independently detected the threat and blocked the malicious releases before they could be officially published. Visiting the plugin listings now reflects the removal of these compromised versions.

Affected

Six WordPress plugins developed by WP Connect

Actions

  • Check if any of the six WP Connect plugins are installed on your sites.
  • Remove the affected plugins immediately if present.
  • Audit your WordPress installations for signs of arbitrary code execution or backdoors.
  • Review developer account security to prevent similar compromises.
