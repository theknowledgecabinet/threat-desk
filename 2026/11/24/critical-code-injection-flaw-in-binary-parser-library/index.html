Critical code injection flaw in binary-parser library

A critical vulnerability in the binary-parser library allows attackers to execute arbitrary JavaScript by manipulating parser definitions.

CVE-2026-134814

A critical code injection vulnerability, tracked as CVE-2026-134814, has been disclosed in the binary-parser library. The flaw affects versions prior to 2.3.1 and carries a CVSS 4.0 base score of 9.2.

According to the National Vulnerability Database, the vulnerability allows attackers who control parser definitions to inject JavaScript through string-typed options passed unvalidated by Context.generateOption(). Attackers can supply crafted values for length, lengthInBytes, key, tag, offset, or namely() aliases to execute arbitrary JavaScript in the Node.js process when the parser is compiled.

CISA has listed the vulnerability as not currently known to be exploited in the wild.

Affected

binary-parser versions prior to 2.3.1

Actions

  • Upgrade binary-parser to version 2.3.1 or later
  • Audit code for untrusted input passed to parser definitions
  • Validate string-typed options before passing them to Context.generateOption()
