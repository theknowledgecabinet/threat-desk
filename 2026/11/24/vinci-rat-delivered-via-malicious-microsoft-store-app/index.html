Vinci RAT delivered via malicious Microsoft Store app

Analysts identified a campaign using a legitimate Microsoft Store listing to install a backdoor that deploys Vinci RAT, allowing remote control of Windows systems.

eSentire’s Threat Response Unit documented an intrusion in early November 2026 where a user seeking a screenshot tool was redirected to a fake site serving a signed installer. This installer directed the user to 'Setup Assistant', a genuine Microsoft Store app published by ETPS Ltd, which acted as a backdoor. Unlike previous campaigns using fake storefronts, this attack leveraged a real store listing to establish trust.

Once installed, the app contacted a command-and-control server to monitor specific files and execute PowerShell or JavaScript commands. In the investigated case, this access launched a loader that retrieved Vinci RAT from a separate domain and created a Windows scheduled task running every 10 minutes to maintain persistence. The malware gathered system details and supported reverse shells, though not all capabilities were confirmed as used in the specific incident.

eSentire noted that Microsoft initially stated the app did not violate its terms after researchers reported it via the Store’s abuse form. The report does not confirm whether the listing was subsequently removed. The package metadata indicated a release date of 1 June 2026, suggesting the app may have been available for five months prior to the investigation.

Affected

Windows PCs; Microsoft Store app 'Setup Assistant' (published by ETPS Ltd)

Actions

  • Isolate devices exhibiting unexpected Store app installations, PowerShell activity, or recurring scheduled tasks.
  • Review endpoint, DNS, and proxy logs for connections to the reported IoCs.
  • Restrict Microsoft Store installations on managed devices using Intune, AppLocker, or Windows Defender Application Control.
  • Review unfamiliar apps before approving them on managed endpoints.
