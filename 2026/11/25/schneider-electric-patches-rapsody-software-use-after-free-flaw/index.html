Schneider Electric patches Rapsody software use-after-free flaw

CISA has published an advisory for a use-after-free vulnerability in Schneider Electric EcoStruxure Power Build Rapsody software that allows local code execution via malicious files.

CVE-2026-119055

Schneider Electric has identified a use-after-free vulnerability (CVE-2026-119055) in its EcoStruxure Power Build Rapsody software. The flaw, classified as CWE-416, permits a local attacker to execute arbitrary code by tricking an end user into opening a specially crafted malicious SSD file.

The vulnerability affects multiple regional versions of the software, including French, Spanish, Portuguese, Belgian, international, and Dutch builds. According to the CISA advisory, failure to apply the remediations may risk memory corruption, heap-based buffer overflow, and/or stack-based buffer overflow.

The National Vulnerability Database lists the CVSS 4.0 base score as 4.6 (medium). CISA does not currently list this vulnerability as known exploited. Schneider Electric has released fixed versions for all affected regional builds.

Affected

EcoStruxure Power Build Rapsody software versions: FR <=2.9.1.0, ESP <=2.8.5.0301, PT <=2.8.7.0101, BEL(FR) <=2.8.8.0201, BEL(EN) <=2.8.3.0201, INT(EN) <=2.8.4.0401, INT(FR) <=2.8.6.0000, NL <=2.8.2.0000

Actions

  • Update EcoStruxure Power Build Rapsody software to the fixed versions specified by Schneider Electric (e.g., FR V2.9.12.0101, ESP V2.9.5.0000).
  • Restrict user permissions to prevent the execution of untrusted SSD files.
  • Monitor for unusual local activity on systems running the affected software versions.
