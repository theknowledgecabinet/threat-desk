Ghostscript sandbox escape enables RCE via crafted file uploads

Security firm pwn.ai demonstrated that a now-patched Ghostscript flaw allows crafted file uploads to escape the sandbox and execute remote code on Linux servers.

Security firm pwn.ai has demonstrated a vulnerability in Ghostscript that allows an attacker to escape the program's security sandbox and execute commands on the server. The flaw is triggered by crafted file uploads, specifically PDFs, PostScript files, or images, which are often processed by Ghostscript on Linux servers without the application calling it directly.

The researchers noted that many applications rely on Ghostscript to convert uploaded documents into other formats, creating a significant attack surface for remote code execution. The vulnerability has since been patched by the vendor.

Defenders should ensure their systems are updated with the latest security fixes to mitigate this risk.

Affected

Ghostscript

Actions

  • Apply the latest security patches for Ghostscript.
  • Review server configurations to limit direct access to document conversion services.
  • Monitor for unexpected command execution in environments processing user-uploaded files.
