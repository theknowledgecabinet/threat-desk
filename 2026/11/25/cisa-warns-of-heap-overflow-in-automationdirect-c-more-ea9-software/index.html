CISA warns of heap overflow in AutomationDirect C-More EA9 software

A heap-based buffer overflow in C-More EA9 Programming Software could allow arbitrary code execution if users open a malicious file.

CVE-2026-127280

CISA has issued an advisory for a vulnerability in AutomationDirect C-More EA9 Programming Software. The flaw, identified as CVE-2026-127280, is a heap-based buffer overflow that occurs when the software fails to adequately validate data read from a project file before using it in heap memory operations.

According to the advisory, a crafted file causes a heap buffer overrun during file open, resulting in heap corruption and instability. Successful exploitation could allow attackers to corrupt application memory and cause a crash, potentially leading to arbitrary code execution. The attack vector requires a user to be convinced to open a malicious project file delivered through channels such as email, file sharing, or removable media.

The vulnerability affects C-More EA9 Programming Software versions up to and including V6.80. It carries a CVSS v3.1 base score of 7.8 (High) and a CVSS v4.0 score of 8.4 (High). The vulnerability was reported to CISA by rgod of TrendAI Zero Day Initiative.

Affected

AutomationDirect C-More EA9 Programming Software <=V6.80

Actions

  • Update C-More EA9 Programming Software to V6.81.
  • Minimise network exposure for control system devices and ensure they are not accessible from the internet.
  • Locate control system networks behind firewalls and isolate them from business networks.
  • Use secure methods such as VPNs for remote access, keeping them updated to the most current version.
