CISA adds Drupal, Idunno, and Optimizely flaws to KEV catalogue

CISA has listed three actively exploited vulnerabilities, including a critical Drupal core flaw, in its Known Exploited Vulnerabilities catalogue, setting a 27 November deadline for federal agencies.

CVE-2026-132165CVE-2026-131914CVE-2026-132224

The US Cybersecurity and Infrastructure Security Agency (CISA) added three vulnerabilities to its Known Exploited Vulnerabilities (KEV) catalogue on 24 November 2026. The list includes CVE-2026-132165, a critical remote code execution flaw in Drupal core; CVE-2026-131914, a critical deserialization vulnerability in the Idunno AntiCsrf library; and CVE-2026-132224, a high-severity issue in Optimizely Web Experimentation. Federal civilian agencies are required to address these flaws by 27 November 2026 under Binding Operational Directive 22-01.

CVE-2026-132165 allows an unauthenticated attacker to abuse the Drupal installation script, install.php, to reinstall the platform and gain full control of the website. The Drupal Security Team confirmed that attacks against live sites were reported as early as 19 November 2026. The flaw was discovered by Anthropic’s open-source software scanner. While restricting web server write access to settings.php blocks some attack paths, it does not mitigate all vectors.

CVE-2026-131914 affects the legacy Idunno AntiCsrf ASP.NET library, allowing unauthenticated remote code execution via a crafted HTTP POST request. Mandiant confirmed active exploitation but has not attributed the attacks to a specific threat actor. As the library is no longer maintained, no official patch is available; organisations are advised to remove it and replace it with a supported anti-CSRF solution.

CVE-2026-132224 involves improper handling of the account signup process in Optimizely Web Experimentation, allowing attackers to inject malicious JavaScript into projectJS fields. This vulnerability was exploited to compromise hundreds of websites and deliver scripts designed to steal payment card information and hijack cryptocurrency transactions. Optimizely addressed the vulnerability on 17 November 2026.

Affected

Drupal Core (versions prior to 10.6.22, 11.3.22, or 11.4.13); Idunno AntiCsrf (versions through 0.9.1 Beta); Optimizely Web Experimentation (versions before 2026-11-17)

Actions

  • Update Drupal to version 10.6.22, 11.3.22, or 11.4.13, or a later supported release.
  • Block public access to /core/install.php at the web server and verify from outside the network that the installer no longer loads.
  • Remove the Idunno AntiCsrf library and replace it with a supported anti-CSRF solution.
  • Review web server and application logs for unexpected installer requests, unfamiliar administrator accounts, and changes to settings.php.
