Dell patches critical 9.9 flaw in Enterprise SONiC

A critical argument injection vulnerability in Dell Enterprise SONiC allows low-privileged remote attackers to execute arbitrary commands on network switches.

CVE-2026-103782

Dell Technologies has released a patch for CVE-2026-103782, a critical vulnerability in Dell Enterprise SONiC Distribution. The flaw, assigned a CVSS 3.1 base score of 9.9, is classified as an argument injection issue that permits a low-privileged remote attacker to execute arbitrary commands and access unauthorised filesystem resources. Dell disclosed the advisory on 19 November 2026, noting that the vulnerability affects software versions prior to 4.6.1.

According to Dell’s severity rating, the flaw has low attack complexity and does not require user interaction, though it is not currently listed by CISA as known exploited. The advisory identifies several affected PowerSwitch platforms, including the E3200-ON series, N3200-ON, S3248T-ON, and S5248F-ON. Administrators are advised to verify the installed SONiC version on each device rather than relying solely on hardware model numbers, as the affected-products table may not cover every supported version.

Dell recommends upgrading affected systems to version 4.6.1, available via Dell My Account. Before applying the update, organisations should back up switch configurations and plan for service restoration in case of failure. If immediate patching is not possible, limiting management access to trusted networks and restricting low-privilege accounts can reduce exposure, though these measures do not remove the vulnerability.

Affected

Dell Enterprise SONiC Distribution versions prior to 4.6.1; PowerSwitch platforms including E3200-ON series, N3200-ON, S3248T-ON, and S5248F-ON

Actions

  • Upgrade affected systems to Dell Enterprise SONiC version 4.6.1
  • Back up switch configurations before applying the update
  • Verify installed SONiC versions on all switches rather than relying on hardware models
  • Limit management access to trusted networks if patching is delayed
