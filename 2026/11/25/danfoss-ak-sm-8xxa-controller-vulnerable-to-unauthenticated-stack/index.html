Danfoss AK-SM 8xxA controller vulnerable to unauthenticated stack-based buffer overflow

CISA has issued an advisory for a critical stack-based buffer overflow in Danfoss AK-SM 8xxA Series controllers that hypothetically allows potential arbitrary code execution without authentication.

CVE-2026-129713

CISA has published an ICS advisory (ICSa-26-328-03) detailing a critical vulnerability in the Danfoss AK-SM 8xxA Series controller. The flaw, identified as CVE-2026-129713, is a stack-based buffer overflow in an unauthenticated CGI handler. According to the advisory, remote attackers can send specially crafted HTTP/S POST requests to trigger memory corruption, causing the webserver to restart and hypothetically potentially allowing arbitrary code execution with webserver privileges.

The vulnerability carries a CVSS v3.1 base score of 9.8 (Critical) and a CVSS v4.0 score of 9.3. It was reported to CISA by Carlo Meijer of Midnight Blue. CISA notes that the vulnerability is not currently listed as known exploited. The affected product is deployed worldwide in commercial facilities, with Danfoss headquartered in Denmark.

Danfoss has stated that the vulnerability will be addressed in an upcoming software release for the AK-SM 800A Series, specifically version 5.5.x. Additionally, the vendor plans to remove the ability for users to disable Strict Mode in future releases. CISA recommends minimising network exposure for control system devices and ensuring they are not accessible from the internet.

Affected

Danfoss AK-SM8xxA <=5.4.0

Actions

  • Ensure control system devices are not accessible from the internet.
  • Locate control system networks behind firewalls and isolate them from business networks.
  • Use Virtual Private Networks (VPNs) for remote access, keeping them updated to the most current version.
  • Monitor for the upcoming Danfoss software release (version 5.5.x) to patch the vulnerability.
