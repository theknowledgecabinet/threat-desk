Broadcom patches critical VMware ESX and vCenter flaws

Broadcom has released cumulative updates for 23 vulnerabilities, including critical authentication bypass and code execution issues in VMware ESX and vCenter.

CVE-2026-123903CVE-2026-123910CVE-2026-123911CVE-2026-123912

Broadcom announced on Tuesday that it has released patches for 23 vulnerabilities across multiple VMware products. The vCenter updates address seven bugs, most notably a critical authentication bypass in the VMware Directory Service tracked as CVE-2026-123903, which carries a CVSS score of 9.8. The fixes also resolve three denial-of-service issues, a local privilege escalation in a vpxd service script, an arbitrary file write vulnerability, and a security policy enforcement failure in the vSphere Distributed Switch.

The ESX updates resolve seven security issues, including three critical-severity weaknesses that allow code execution on the host. CVE-2026-123910 and CVE-2026-123911 are heap out-of-bounds write and use-after-free flaws in the I/O filter service, both rated 9.8. CVE-2026-123912 is an out-of-bounds write in the XHCI USB controller requiring local administrative privileges, rated 9.3. Broadcom noted that on ESX, exploitation is contained within the VMX sandbox, whereas on Workstation and Fusion, it may lead to code execution on the host machine.

Additional fixes cover eight flaws in Avi Load Balancer, which could lead to code execution with root privileges and privilege escalation, and one denial-of-service issue in VMware Tools. Broadcom stated that vCenter version 8.0 U3m already contains the fixes, so those customers do not need to update again. However, deployments of vCenter 9.1.x, ESX, VMware Tools, Workstation, Fusion, and Avi Load Balancer require the new updates. The company did not confirm whether any of these vulnerabilities are being exploited in the wild.

Affected

VMware vCenter (9.1.x), VMware ESX, VMware Tools, VMware Workstation, VMware Fusion, Avi Load Balancer

Actions

  • Apply the latest cumulative patches to vCenter 9.1.x, ESX, VMware Tools, Workstation, Fusion, and Avi Load Balancer.
  • Verify that vCenter 8.0 U3m deployments are up to date, as they already contain the fixes.
  • Ensure SDDC Manager updates from VMSA-2026-0009 are applied, as they are not included in this specific advisory.
