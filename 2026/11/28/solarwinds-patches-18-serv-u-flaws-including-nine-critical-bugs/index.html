SolarWinds patches 18 Serv-U flaws, including nine critical bugs

SolarWinds released Serv-U 2026.4 to fix 18 vulnerabilities, nine of which are critical, with two allowing privilege escalation to root on Linux systems.

SolarWinds released Serv-U 2026.4 on 24 November 2026, addressing 18 vulnerabilities, including nine critical flaws. The release notes identify CVE-2026-123172 and CVE-2026-123168 as the two flaws that could grant attackers root access on Linux servers, both carrying a CVSS 3.1 base score of 9.1. While the risk is lower on Windows, the update also fixes a high-severity command injection flaw, CVE-2026-123166, that affects only Windows installations.

Several other critical flaws allow users with existing administrative access to gain elevated privileges. CVE-2026-82322 could let a domain group administrator become a Serv-U server administrator, while CVE-2026-82320 and CVE-2026-82321 could let domain administrators gain system administrator rights. Additionally, CVE-2026-82315 and CVE-2026-82316 involve file access race conditions that could allow privileged users to access or modify protected files, potentially enabling code execution, while CVE-2026-82319 involves a file access race condition and privilege escalation.

The release notes do not report active exploitation of these newly disclosed flaws. SolarWinds credited the Intigriti Bug Bounty Program for all nine critical reports. The update also includes OpenSSL 3.5 LTS and stops Serv-U from writing multi-factor authentication codes to its logs.

Affected

SolarWinds Serv-U versions prior to 2026.4

Actions

  • Upgrade to Serv-U 2026.4, prioritising internet-facing Linux servers.
  • Back up the configuration and export the server identifier before installing the update.
  • Verify the server reports version 2026.4 and test sign-in and file transfer workflows.
  • Review recent administrator changes and unexpected file activity to check for prior compromise.
