Indian juvenile held for selling Agniveer data on dark web

A 14-year-old was detained after allegedly extracting personal data from 4,000 former Agniveers via an unauthorised access to a government registration portal.

Indian investigators have detained a 14-year-old for allegedly gaining unauthorised access to a test website designed for former Agniveers to register for employment opportunities in other government departments. According to the report, the juvenile allegedly extracted personal information from the site and posted an advertisement on the dark web claiming to possess the data of approximately 4,000 individuals.

Affected

Test website for former Agniveer registration

Actions

  • Audit access controls and authentication mechanisms on all government-facing registration portals, including test environments.
  • Implement strict monitoring and alerting for unauthorised data extraction or bulk export attempts.
  • Ensure that test and staging environments are isolated from production networks and do not contain live personal data.
