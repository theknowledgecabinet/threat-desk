Critical NGINX flaws enable unauthenticated remote code execution

NGINX has released fixes for five critical vulnerabilities, including use-after-free and integer underflow bugs, that allow unauthenticated attackers to execute arbitrary code.

CVE-2026-113425CVE-2026-121810CVE-2026-123007CVE-2026-123633CVE-2026-123634

NGINX announced on 18 November 2026 that it has fixed multiple critical vulnerabilities affecting releases 1.9.5 through 1.31.8. The flaws, identified as CVE-2026-113425, CVE-2026-121810, CVE-2026-123007, CVE-2026-123633, and CVE-2026-123634, permit remote unauthenticated attackers to crash worker processes or execute arbitrary code. Cisco’s PSIRT confirmed that proof-of-concept exploit code is available, though it is not aware of any malicious use to date.

The vulnerabilities include a use-after-free in the mail proxy module and HTTP/2 proxy handling, as well as an integer underflow in HTTP/2 flow control. According to Palo Alto Networks, these issues specifically impact configurations where HTTP/2 is enabled. The vendor noted that the flaws allow attackers to trigger heap-based buffer overflows or prematurely free memory for active connections, leading to remote code execution.

Major vendors including Fortinet, Cisco, and Palo Alto Networks have published advisories detailing the impact on their respective product lines. While Fortinet is still investigating the impact on its portfolio, Cisco has identified several affected products, including Identity Services Engine and NX-OS Software, with fixed releases scheduled for December 2026. Palo Alto Networks has confirmed that PAN-OS versions prior to specific hotfixes are vulnerable, with patches available for immediate deployment.

Affected

NGINX OSS versions 1.9.5 - 1.31.8; PAN-OS 12.2 < 12.2.4-h3, 12.1 >= 12.1.5 < 12.1.7-h15, 11.2 >= 11.2.8 < 11.2.10-h19; Cisco ISE 3.5, NX-OS Software, UCS Director, and various Cisco cloud and collaboration products.

Actions

  • Upgrade NGINX to version 1.31.9 (mainline) or 1.30.7 (stable).
  • For Palo Alto Networks, upgrade PAN-OS to 12.2.4-h3, 12.1.7-h15, or 11.2.10-h19 or later.
  • Disable the HTTP/2 option on PAN-OS and Panorama if immediate patching is not possible.
  • Monitor vendor advisories for specific fixed releases of Cisco and Fortinet products.
