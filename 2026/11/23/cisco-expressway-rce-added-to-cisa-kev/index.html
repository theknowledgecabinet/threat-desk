Cisco Expressway RCE added to CISA KEV

Cisco has released a fix for a critical remote code execution flaw in Expressway Series devices that CISA has listed as known exploited.

CVE-2026-76466

Cisco issued a security advisory on 21 October 2026 for CVE-2026-76466, a critical vulnerability in the database service feature of Cisco Expressway Series. The flaw, rated 9.8 on the CVSS v3.1 scale, allows an unauthenticated, remote attacker to execute arbitrary operating system commands as root. The vulnerability stems from the use of persistent cookies and insufficient validation of client certificates when TLS Verify Mode is set to Enabled for clustering.

According to the advisory, an attacker with possession of the cookies can connect to the database service and invoke specific remote procedure call (RPC) commands to achieve this. Cisco confirmed that the vulnerability affects Cisco Expressway-C and Cisco Expressway-E devices, both virtual and appliance versions, if they are running a vulnerable release and are configured in a cluster.

In November 2026, the vulnerability was added to the Known Exploited Vulnerability (KEV) database of the U.S. Cybersecurity and Infrastructure Security Agency (CISA). Cisco stated it does not have direct evidence of active exploitation but strongly recommends upgrading to a fixed software release, as no workarounds are available.

Affected

Cisco Expressway-C and Cisco Expressway-E (virtual and appliance) running X14 and earlier or X15.5.3 and earlier, configured in a cluster.

Actions

  • Upgrade Cisco Expressway Series devices to release X15.5.20 or later.
  • Migrate devices running X14 and earlier to a fixed release.
  • Verify if devices are configured in a cluster, as this is a condition for the vulnerability.
