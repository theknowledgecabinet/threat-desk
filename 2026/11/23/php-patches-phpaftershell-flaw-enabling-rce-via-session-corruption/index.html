PHP patches phpAfterShell flaw enabling RCE via session corruption

PHP has released patches for CVE-2026-126714, a critical vulnerability that allows remote code execution by exploiting interrupted session writes to trigger object deserialization.

CVE-2026-126714

Security firm Depthfirst identified a critical-severity vulnerability in PHP, tracked as CVE-2026-126714 with a CVSS score of 9.2. The flaw, dubbed phpAfterShell, exists because PHP overwrites session files without emptying them first. If a session write operation is interrupted mid-process, the file retains mixed content: fresh session data followed by remnants of the old session. This corruption can cause ordinary strings to be interpreted as serialized object data, leading to remote code execution when the session is subsequently loaded.

According to Depthfirst, attackers can trigger this by controlling data written to a session file and interrupting the write operation, for example through multipart upload progress updates. The issue is related to the earlier PHP2Shell flaws, where PHP’s upload-progress callback could open and decode a file-backed session before the target script began. Although PHP added restrictions on object creation in memory, it did not modify the underlying file update behaviour, leaving the attack path viable.

PHP resolved the issue on 19 November alongside six other critical issues. The vendor notes that successful exploitation requires default session storage to be active, an exploitation route such as upload progress tracking, the PHP process to stop mid-write, a request to call session_start() on the corrupted file, and a deserialization-to-code-execution path. There are no current reports of in-the-wild exploitation of phpAfterShell.

Affected

PHP versions 8.6.0, 8.5.13, 8.4.28, 8.3.37, and 8.2.36

Actions

  • Update PHP to version 8.6.0, 8.5.13, 8.4.28, 8.3.37, or 8.2.36 or later.
  • Review session handling configurations to ensure default session storage is not active if not required.
  • Monitor for unusual session file corruption or deserialization errors in application logs.
