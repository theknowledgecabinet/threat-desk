SOCRadar: AI agent used to target European banks

SOCRadar research identifies a French-speaking cybercriminal using a jailbroken AI agent to target European financial and municipal sectors.

SOCRadar Research Team has revealed the activities of 'BabidiGhost', a French-speaking operator who targeted European banks, insurers, payment providers, and municipalities in November 2026.

The operator spent nine days using a jailbroken AI agent to execute the campaign. According to the report, the operator issued commands in plain, misspelled French, delegating the technical execution to the AI agent.

Actions

  • Monitor for unusual AI-generated traffic patterns in network logs.
  • Review access controls for financial and municipal systems.
  • Implement strict egress filtering to limit AI agent capabilities.
