N-able patches critical SSRF flaw in Mail Assure

N-able has released a patch for a critical server-side request forgery vulnerability discovered during its investigation into a cyberattack on its Mail Assure and SpamExperts services.

CVE-2026-134624

N-able disclosed that it has remediated a critical server-side request forgery (SSRF) vulnerability, tracked as CVE-2026-134624, which was identified during its investigation into a cyberattack targeting its Mail Assure and SpamExperts Hosted Cloud services. The company confirmed that the attack involved a web server where attackers likely accessed stored credentials, leading to the temporary suspension of services including logging, mailbox synchronisation, and the management portal on 16 November.

The vulnerability, which carries a CVSS score of 9.3, exists because the affected service did not restrict the destination of the LDAP synchronisation connection check performed when a relay is configured. This flaw could allow an API user with sufficient privileges to force the vulnerable server to connect to arbitrary internal hosts and ports, identify reachable services, and send crafted data to internal systems.

N-able stated that it has contained the incident, changed credentials, and revoked API and OAuth tokens. Access to the Mail Assure and SpamExperts dashboard and APIs was restored on 21 November. The company reported that exploitation was confined to a single N-able-hosted server and that continued monitoring has found no further malicious activity. A formal root cause analysis is expected within two weeks.

Affected

Mail Assure/SpamExperts (patched in version 20261121.1943)

Actions

  • Update Mail Assure and SpamExperts to version 20261121.1943 or later.
  • Review API and OAuth token usage for any unauthorised access.
  • Monitor for anomalous LDAP synchronisation connection attempts.
  • Wait for the formal root cause analysis for further details.
