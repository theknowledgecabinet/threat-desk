Tampered Q-Dir and DesktopOK installers deploy Python RAT

AhnLab researchers identified malicious installers for two Windows utilities that launch the genuine application while downloading a remote access trojan, compromising trusted software supply chains.

Researchers from AhnLab Security Intelligence Center (ASEC) published findings on 26 November 2026, detailing tampered installers for Q-Dir and DesktopOK distributed via the SoftwareOK platform. The malicious installers launch the legitimate applications, which retain valid digital signatures, while silently downloading a Python-based remote access trojan (RAT) from an external server. This supply chain attack allows operators to execute shell commands, transfer files, and capture screenshots on infected systems.

The malware includes its own Python runtime, ensuring execution even if Python is not installed, and registers a Windows scheduled task for persistence. It also checks running processes against a list of 1,206 security product names to detect defensive tools. ASEC noted that the confirmed versions may not cover all exposed users and did not attribute the campaign to a specific group, though Chinese-language comments were found in the code.

Users are advised to verify SHA-256 hashes against official download pages before installation. A mismatch indicates a tampered file, even if the embedded executable is signed. Reinstalling the utility alone does not remove the trojan, which operates independently via scheduled tasks and specific file paths.

Affected

Q-Dir versions 12.85.0.0, 12.84.0.0, and 12.83.0.0; DesktopOK versions 12.85.0.0 and 12.82.0.0

Actions

  • Uninstall the affected utility and reinstall the latest verified release from the official source.
  • Compare the SHA-256 hash of the new installer with the value published on the official download page.
  • Check for the scheduled task '\UPnp\MicrosoftEdge_dcntel' and files in 'C:\ProgramData\Microsoft\DeviceSync\b2' or 'C:\ProgramData\DeviceSync\b2'.
  • Isolate infected machines from the network and investigate for additional malware or data exfiltration.
