SAP confirms cyber incident amid reports of source code breach

SAP has confirmed a cybersecurity incident following reports that hackers infiltrated its software development infrastructure, potentially gaining access to the company’s source code.

SAP has confirmed a cybersecurity incident following reports that hackers infiltrated its software development infrastructure, potentially gaining access to the company’s source code. In a statement to Recorded Future News, the company said it identified suspicious activity and immediately taken steps to protect its customers and secure its services. SAP stated that its investigation found no evidence of unauthorised access to customer business data, though it did not disclose the nature or extent of the intrusion.

According to Der Spiegel, the attack targeted SAP’s software development environment hosted on GitHub, with attackers obtaining employee authentication tokens that allowed them to copy and modify the company’s source code. The German Press Agency reported that SAP alerted employees to the suspicious activity several days before the incident became public, advising them to assess whether they needed to change login credentials.

SAP launched an internal incident response operation code-named “Project Granite,” which included restricting access to GitHub and halting automated development processes. The company replaced digital keys used to verify that its software was genuine and had not been tampered with. It remains unclear whether the hackers accessed SAP’s proprietary source code or whether any altered code ended up in software delivered to customers.

Affected

SAP software development environment on GitHub

Actions

  • Verify the integrity of software updates using updated digital keys.
  • Rotate authentication tokens and credentials for development environments.
  • Monitor for unauthorised changes in source code repositories.
