Fake Minecraft mod Farmutils-Loader.jar steals session tokens

SonicWall identified a malicious Fabric mod that exfiltrates Minecraft session tokens and deploys a Python infostealer via a blockchain-based C2 channel.

Researchers at SonicWall Capture Labs identified a fake Minecraft mod named Farmutils-Loader.jar, part of the SilentNet malware family active since early 2026. The Java archive poses as a library for the Fabric mod loader; when executed, it reads the player’s active session from memory, capturing the username, unique account identifier, and Minecraft services access token. This token allows unauthorised use of Minecraft services for approximately 24 hours, though it does not expose the player’s Microsoft password.

The loader initiates a background process that downloads a second stage disguised as a PNG image. It locates its command-and-control server via a smart contract on the Polygon blockchain, a technique known as EtherHiding that allows operators to change server addresses without distributing new files. The payload unpacks a bundled Python interpreter and script into a Windows directory, launching the infostealer without requiring a pre-installed Python environment. SonicWall noted that over 1,200 samples of the SilentNet family have been observed in the wild, though the specific infection count for this mod remains unconfirmed.

SonicWall did not recover the second-stage payload, so its exact data collection targets are unconfirmed, though it gathers Minecraft and runtime logs. The malware uses specific HTTP headers and C2 paths for check-ins and log uploads. Because the loader runs outside the game process, closing Minecraft or deleting the JAR file is insufficient if the second stage has already been unpacked.

Affected

Windows systems running Minecraft with the Fabric mod loader

Actions

  • Disconnect affected Windows devices from the network immediately if the JAR was executed.
  • Run a full security scan and review Minecraft account activity from a clean device.
  • Verify mod publishers and download only from official project pages or trusted platforms.
  • Monitor for the presence of files in %LOCALAPPDATA%\Microsoft\Windows\NtProfileIndex\ and associated logs.
