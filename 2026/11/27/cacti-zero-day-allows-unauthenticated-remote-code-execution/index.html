Cacti zero-day allows unauthenticated remote code execution

A stored SQL injection flaw in Cacti enables attackers to execute commands without login if guest access is enabled, with no patch currently available.

Security researcher ek0ms savi0r disclosed a zero-day vulnerability in Cacti, an open-source network monitoring tool, on 26 November 2026. The flaw, tracked as 4HTTP2ROOT or 4HTTP2SHELL, is a stored SQL injection that allows unauthenticated attackers to achieve remote code execution in four HTTP requests if anonymous guest access is enabled. A public proof of concept demonstrated command execution on Cacti 1.2.31, though no exploitation in the wild had been reported as of 27 November 2026.

The vulnerability arises because Cacti does not properly validate settings controlled by guests, allowing database changes that affect polling configurations. While the researcher demonstrated root-level command execution on a test system running as root, commands generally run with the permissions of the affected process. Even without root access, a compromised server could expose credentials used to reach network devices, providing a potential route into other systems.

No CVE identifier, official severity rating, or confirmed patch is available at this time. Administrators are advised to remove the designated Guest User from authentication settings and deactivate the guest account under Console > Configuration > Users. While disabling guest access blocks the demonstrated attack path, it does not repair the underlying SQL injection, so teams should also restrict web interface access to trusted networks and monitor for unusual processes.

Affected

Cacti 1.2.31

Actions

  • Remove the designated Guest User and deactivate the guest account under Console > Configuration > Users.
  • Restrict the web interface to trusted management networks or authenticated VPN users.
  • Ensure the application and its polling processes do not run as root unless required.
  • Review unexpected changes to user settings and polling configurations for signs of compromise.
