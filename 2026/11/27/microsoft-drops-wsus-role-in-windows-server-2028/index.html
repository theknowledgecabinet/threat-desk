Microsoft drops WSUS role in Windows Server 2028

Microsoft is removing the Windows Server Update Services (WSUS) role in Windows Server 2028, encouraging enterprise IT teams to migrate to cloud-based update management solutions.

Microsoft has confirmed that the Windows Server Update Services (WSUS) server role will be removed in Windows Server 2028, the next major release of its server operating system. WSUS, introduced in 2005, allows IT administrators to manage and distribute updates for Microsoft products across corporate networks. While the role was officially deprecated in September 2024, Microsoft stated it would continue to maintain functionality and publish updates through the channel for existing releases.

The removal affects enterprise environments that rely on WSUS for centralised update management but does not impact home users or those using Microsoft Configuration Manager. According to a recently updated support document, WSUS remains available and supported in earlier releases, including Windows Server 2025, for the duration of each release's support lifecycle. Microsoft noted that it recognises the need to manage updates in disconnected and highly controlled environments and will share more details as work progresses.

Microsoft is encouraging organisations to transition to cloud-based solutions such as Windows Autopatch, Microsoft Intune, and Azure Update Manager. In September 2024, Microsoft’s Nir Froimovici stated that while WSUS remains operational, the company is no longer investing in new features. Windows Server 2028 also removes VBScript and the legacy Windows Management Instrumentation Command-line (WMIC) utility to thwart malware and attack tactics abusing them.

Affected

Windows Server 2028

Actions

  • Plan migration from WSUS to cloud-based tools like Windows Autopatch, Microsoft Intune, or Azure Update Manager.
  • Review update management strategies for disconnected or highly controlled environments.
  • Assess dependencies on VBScript and WMIC, which are also being removed in Windows Server 2028.
