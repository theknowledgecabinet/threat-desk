Microsoft releases emergency hotpatch for Windows Server 2025 crashes

An out-of-band update fixes stop errors triggered by IPv6 route expiration following the November 2026 security hotpatch.

Microsoft has released an emergency out-of-band (OOB) update, KB5138318, to address unexpected stop errors on Windows Server 2025. According to Microsoft, the issue affects a limited number of servers with Router Advertisement enabled that receive time-bound IPv6 routes. The crashes occur when a route timer expires, resulting in stop error 0x139 (KERNEL_SECURITY_CHECK_FAILURE).

The problem was triggered after installing the November 2026 Windows security hotpatch update, KB5131077. Microsoft stated that the new OOB update is rolling out automatically to affected devices enrolled in hotpatch updates via Windows Update. The update takes effect without requiring a restart for IT administrators or users.

The November 2026 hotpatch updates have also caused other issues for Windows 11 users, including installation and launch problems for Office and third-party applications, as well as printing issues on systems running Forcepoint's DLP Endpoint Agent.

Affected

Windows Server 2025 devices with Router Advertisement enabled that receive time-bound IPv6 routes, after installing KB5131077

Actions

  • Ensure Windows Update is enabled to receive the automatic KB5138318 hotpatch.
  • Monitor servers for stop error 0x139 if IPv6 routes are time-bound.
  • Check for related application and printing issues on Windows 11 systems after the November hotpatch.
