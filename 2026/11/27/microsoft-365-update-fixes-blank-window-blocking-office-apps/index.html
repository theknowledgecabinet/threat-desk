Microsoft 365 update fixes blank window blocking Office apps

A startup bug in Microsoft 365 displayed a blank white dialog box that prevented users from accessing Word, Excel, and Outlook, now resolved in a specific build.

Microsoft has released a fix for a Microsoft 365 startup issue that caused a blank white window to appear when opening Word, Excel, or Outlook. According to a support notice dated 23 November 2026, the issue affected users who could not dismiss the dialog box, rendering the underlying application unusable. The notice identifies Version 2611, Build 16.0.20625.20142, as the release that resolves the problem.

The company did not specify the cause of the dialog, which earlier builds were affected, or the number of users impacted. Microsoft clarified that this was a desktop startup problem, distinct from the separate Microsoft 365 outage on 12–13 November 2026, which involved Exchange Online mailbox access issues. The support notice also lists PowerPoint, Access, and OneNote for Microsoft 365 as affected applications.

For users unable to reach the update menu due to the blank window, Microsoft advises using the Command Prompt as an administrator to force the update. The recommended command is `"%programfiles%\Common Files\Microsoft Shared\ClickToRun\officec2rclient.exe" /update user updatetoversion=16.0.20625.20142`. After running the command, users should restart the application and verify the build number under File > Account.

Affected

Microsoft 365 (Word, Excel, Outlook, PowerPoint, Access, OneNote); fixed in Version 2611, Build 16.0.20625.20142

Actions

  • Update to Version 2611, Build 16.0.20625.20142 via File > Account > Update Options > Update Now.
  • If the update menu is inaccessible, run the Click-to-Run updater command in an elevated Command Prompt.
  • Verify the installed build number under File > Account after the update completes.
