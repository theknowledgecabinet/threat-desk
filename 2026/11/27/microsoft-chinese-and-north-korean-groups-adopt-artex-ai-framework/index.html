Microsoft: Chinese and North Korean groups adopt ARTEX AI framework

Microsoft and the Cloud Security Alliance report that nation-state and criminal groups are using the ARTEX autonomous penetration testing framework to accelerate attack chains and achieve privileged access in under three hours.

Microsoft revealed on 25 November that Chinese-nexus actors Salt Typhoon, Crystal Typhoon, Storm-0940 and Storm-3358, along with DPRK-linked actors Onyx Sleet and Pearl Sleet, have integrated the ARTEX AI offensive framework into their toolkits. The groups are using the tool to automate network reconnaissance, credential attacks, and web application exploitation. A concurrent Cloud Security Alliance report described ARTEX and similar Agentic Offensive Frameworks as the 'third wave' of AI-driven threats, noting they enable threat actors to reach privileged access in under three hours and allow low-resourced criminals to execute complex attack chains at scale.

ARTEX is an open-source, AI model-driven autonomous penetration testing framework released on GitHub in July 2026. Written in Go with an embedded Next.js web console, it functions as an offensive command-and-control platform that communicates with AI agents and large language models. Microsoft noted that while ARTEX does not introduce new attack techniques, it allows actors to vary network indicators such as source IP addresses or user agent strings to bypass static or signature-based detection. Infrawatch analysis published on 24 November identified more than 130 variants of ARTEX in the wild, with server activity rising sharply in early November following a surge in intrusions in October.

Microsoft advised defenders to inventory internet-facing assets and prioritise fixes on resources leading to sensitive data or privileged identities. Organisations should block and slow down attacks on web applications and APIs by capping request rates, and map what exposed assets or stolen credentials could reach to enable faster response. Additionally, endpoint protection should be run on every internet-facing server, outbound connections from web servers should be restricted, and conditional access should be applied to every user and workload identity.

Affected

ARTEX AI offensive framework

Actions

  • Inventory internet-facing assets and prioritise fixes on resources leading to sensitive data or privileged identities.
  • Block and slow down attacks on web applications and APIs by capping how many requests one client can send in a short time.
  • Run endpoint protection on every internet-facing server and keep it in blocking mode.
  • Restrict outbound connections from web servers to only the destinations each server needs.
