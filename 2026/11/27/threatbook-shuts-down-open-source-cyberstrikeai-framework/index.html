ThreatBook shuts down open-source CyberStrikeAI framework

ThreatBook has removed the open-source CyberStrikeAI framework from GitHub after it was used in multiple malicious campaigns, leaving only a closed-source enterprise edition for authorised testers.

Agentic security firm ThreatBook announced on 26 November that it has permanently removed the open-source version of CyberStrikeAI from GitHub and other communities. The company, which acquired the tool in September, cited increased misuse by attackers worldwide to orchestrate malicious attacks at unprecedented speeds and scale.

The takedown follows a warning from the Indian Computer Emergency Response Team (CERT-In) that a threat group tracked as ‘Crafty Falcon’ was targeting financial and cryptocurrency organisations using AI-powered tools, including CyberStrikeAI. A 25 November report from the Shadowserver Foundation observed more than 4,200 servers running identified agentic offensive frameworks (AOFs) as of 23 November, with 6% linked to CyberStrikeAI.

ThreatBook stated that the technology is neutral and should be used solely by security teams for self-assessment. A closed-source enterprise edition, part of the RedAgents offering, remains available to verified enterprises with valid authorisation for their network assets. The firm advised users to be vigilant of forks appearing elsewhere, which could compromise security.

Affected

CyberStrikeAI (Open Source Version)

Actions

  • Be vigilant of forks that appear elsewhere, which could compromise security.
  • Ensure that any use of the enterprise edition is conducted by verified enterprises holding valid authorisation for the network assets they test.
