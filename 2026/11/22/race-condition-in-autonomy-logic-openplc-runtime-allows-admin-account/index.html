Race condition in Autonomy Logic OpenPLC Runtime allows admin account creation

CISA has issued an advisory for a high-severity race condition in Autonomy Logic OpenPLC Runtime that permits the creation of unauthenticated administrator accounts.

CVE-2026-126088

CISA published ICS Advisory ICSA-26-323-01 detailing a vulnerability in Autonomy Logic OpenPLC Runtime. The flaw, identified as CVE-2026-126088, is a race condition where multiple concurrent requests can pass an existence check before a user is committed to the system. This behaviour results in the creation of several unauthenticated admin accounts.

The vulnerability affects versions 4.2.4 and prior. CISA rates the CVSS v3.1 base score as 8.1 (High) and the CVSS 4.0 base score as 9.2 (Critical). The advisory notes that the product is deployed worldwide in critical infrastructure sectors including critical manufacturing, energy, transportation systems, and water and wastewater systems. CISA does not list the vulnerability as known exploited in the National Vulnerability Database.

Autonomy Logic has released a fix for the issue. CISA recommends that organisations update to OpenPLC Runtime version 4.3.0 or later. The agency also advises minimising network exposure for control system devices and ensuring they are not accessible from the internet.

Affected

Autonomy Logic OpenPLC Runtime <=4.2.4

Actions

  • Update to OpenPLC Runtime version 4.3.0 or later.
  • Minimise network exposure for control system devices and ensure they are not accessible from the internet.
  • Locate control system networks and remote devices behind firewalls and isolate them from business networks.
