PHP releases updates for 18 flaws, including critical RCE bugs

The PHP development team has released security updates for all supported branches to address 18 vulnerabilities, including critical remote code execution flaws exploitable by unauthenticated attackers.

The PHP development team released security updates on 19 November to fix 18 vulnerabilities across all supported branches. According to Lawrence Abrams, the updates address critical flaws that could allow unauthenticated attackers to remotely execute code on vulnerable servers.

The new releases are now available for the current supported versions: PHP 8.5.13, 8.4.28, 8.3.37, and 8.2.36. Security firm Aikido reported on the details of the fixes.

Affected

PHP 8.5.13, 8.4.28, 8.3.37, and 8.2.36

Actions

  • Update PHP installations to version 8.5.13, 8.4.28, 8.3.37, or 8.2.36 immediately.
  • Verify that all supported PHP branches in your environment have been patched.
  • Review server logs for signs of unauthenticated remote code execution attempts.
