F5 releases emergency patches for five critical BIG-IP RCE flaws

F5 has issued out-of-band hotfixes for five critical stack-based buffer overflow vulnerabilities in BIG-IP APM and iRules that allow unauthenticated remote code execution.

CVE-2026-121805CVE-2026-120292CVE-2026-120285CVE-2026-116953CVE-2026-123637CVE-2026-126822

F5 warned customers to patch five critical vulnerabilities, tracked as CVE-2026-121805, CVE-2026-120292, CVE-2026-120285, CVE-2026-116953, and CVE-2026-123637, affecting the BIG-IP Access Policy Manager (APM) and iRules features. These stack-based buffer overflow flaws enable unauthenticated threat actors to terminate the Traffic Management Microkernel (TMM) and execute arbitrary code remotely on systems with vulnerable configurations.

The company also released engineering hotfixes for a high-severity BIG-IP APM SAML vulnerability (CVE-2026-126822) stemming from an integer underflow weakness, which can be abused for denial-of-service attacks. F5 stated that there are no mitigation measures for these flaws and advised security teams to install the out-of-band hotfixes released on Wednesday.

While F5 has not flagged these specific issues as actively exploited, Shadowserver tracks more than 177,000 BIG-IP instances and over 14,600 IP addresses with BIG-IP APM fingerprints exposed online. CISA has previously flagged seven F5 vulnerabilities as actively exploited since November 2021, and F5 recently patched a critical BIG-IP APM zero-day (CVE-2026-94127) in September.

Affected

BIG-IP Access Policy Manager (APM), BIG-IP iRules

Actions

  • Install the out-of-band hotfixes released by F5 on Wednesday
  • Upgrade systems to the latest version as soon as possible
  • Audit exposed BIG-IP instances for APM fingerprints
