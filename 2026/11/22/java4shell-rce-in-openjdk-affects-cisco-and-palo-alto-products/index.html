Java4Shell RCE in OpenJDK affects Cisco and Palo Alto products

Oracle has released fixes for a critical buffer overflow in the Base64 decoder that allows remote code execution on x86-64 systems with AVX-512 support.

CVE-2026-114938

Oracle announced on 17 November 2026 that it has released fixes for CVE-2026-114938, a critical vulnerability in the HotSpot JVM's optimised Base64 decoder. The flaw, dubbed 'Java4Shell', is a buffer overflow that occurs when processing Base64 encoded content on x86-64 platforms with AVX-512 VBMI support. An unauthenticated remote attacker can exploit this to achieve remote code execution by supplying specially crafted Base64 input to affected applications.

Cisco published an advisory on 18 November 2026 stating that several of its products are affected, including Secure Network Analytics, Cisco IQ Virtual Appliance, and various Unified Communications products. Cisco confirmed that proof-of-concept exploit code is available but is not aware of any malicious use. The company noted that there are no workarounds and that fixed releases are pending for most affected products, with some specific versions like Secure Network Analytics 7.6.1 planned for patching.

Palo Alto Networks assessed the vulnerability as Critical with a CVSS 4.0 score of 9.2. The vendor identified that its Idira products, including Privilege Threat Analytics and Remote Access Connector, are affected. Fixes are available for these products, such as upgrading Privilege Threat Analytics to version 15.2.3 or later. Palo Alto Networks stated that PAN-OS based products are not impacted and that SaaS products are being managed directly by the vendor.

Affected

Oracle Java SE (8u511b33-perf, 17.0.21.0.3, 21.0.13.0.3, 25.0.5.0.3, 27.0.1.0.3), Oracle GraalVM for JDK (17.0.21.0.3, 21.0.13.0.3), Oracle GraalVM Enterprise Edition (21.3.20.0.3), Cisco Secure Network Analytics, Cisco IQ Virtual Appliance, Palo Alto Networks Idira Privilege Threat Analytics, Idira Remote Access Connector, Idira Secure Access with an HTML5 Gateway (On-Prem)

Actions

  • Apply the Oracle Critical Security Patch Update for November 2026 to update Java runtimes.
  • Upgrade affected Cisco products to the fixed releases listed in the Cisco Security Advisory.
  • Upgrade Palo Alto Networks Idira products to the specified fixed versions, such as Privilege Threat Analytics 15.2.3.
  • Monitor vendor advisories for updates on fixed release dates for products where patches are still TBD.
