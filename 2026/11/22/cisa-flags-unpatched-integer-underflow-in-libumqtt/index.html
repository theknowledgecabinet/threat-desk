CISA flags unpatched integer underflow in libumqtt

CISA has issued an advisory for an integer underflow vulnerability in libumqtt that allows remote denial of service, memory corruption, or information disclosure, with no vendor fix available.

CVE-2026-125132

CISA published ICS Advisory ICSA-26-323-03, identifying an integer underflow (CWE-191) in libumqtt. The agency states that successful exploitation could allow a remote attacker to cause a denial of service, memory corruption, or information disclosure. The vulnerability affects libumqtt versions 1.1.1 and earlier.

The National Vulnerability Database lists the CVSS 4.0 base score as 8.8 (High), while CISA’s CVSS 3.1 score is 8.6 (High). CISA notes that the repository owners did not respond to coordination requests, meaning no official remediation is currently available. The vulnerability was reported to CISA by Joseph Devasia.

CISA recommends minimising network exposure for control system devices and ensuring they are not accessible from the internet. Organisations should locate control system networks behind firewalls, isolated from business networks, and use secure methods such as VPNs when remote access is required.

Affected

libumqtt <=1.1.1

Actions

  • Minimise network exposure for control system devices and ensure they are not accessible from the internet.
  • Locate control system networks and remote devices behind firewalls, isolating them from business networks.
  • Use secure methods such as Virtual Private Networks (VPNs) when remote access is required, keeping them updated.
  • Contact libumqtt maintainers directly for support as no official patch is available.
