Ruby patches 'Ruby2Shell' heap overflow with RCE potential

Ruby has released updates for seven vulnerabilities, including a heap-based buffer overflow in string case conversion that allows unauthenticated remote code execution in specific single-byte encodings.

CVE-2026-132825

Ruby versions 4.0.10, 3.4.13, and 3.3.14 resolve seven flaws, primarily in the regular expression engine and string case conversion. The most severe is CVE-2026-132825, a heap-based buffer overflow with a CVSS score of 7.4. Dubbed 'Ruby2Shell', this flaw occurs when converting characters in single-byte encodings such as ISO-8859-1 or Windows-1252, where Ruby may write one byte past the output buffer. For example, converting the German character ß to uppercase produces 'SS', but the code checks for only one byte of space, potentially corrupting adjacent heap memory.

Veria Labs reports that unauthenticated attackers could trigger this defect from Rails, classic-style Sinatra, and potentially other frameworks. WatchTowr notes that any Ruby application changing the case of external text in a single-byte encoding is affected. While proof-of-concept code exists for five of the vulnerabilities, WatchTowr principal threat intelligence specialist Yordan Ganchev stated that successful exploitation in production is likely challenging due to memory layout constraints, the need for specific non-glibc memory allocators, and Address Space Layout Randomization (ASLR). Malformed requests are more likely to result in denial-of-service than successful code execution.

According to Veria Labs, GitHub Enterprise Server is affected, while Chatwoot, GitLab, Mastodon, OpenProject, and the Discourse base image have already patched the bug. Veria Labs plans to release a public proof-of-concept after major vendors have rolled out patches. The other four vulnerabilities with RCE proof-of-concept code include a double free, two integer overflows, and a heap-based buffer overflow, though their CVE identifiers have not yet been assigned.

Affected

Ruby before 3.3.14, 3.4.13, and 4.0.10

Actions

  • Upgrade Ruby to version 4.0.10, 3.4.13, or 3.3.14 immediately.
  • Audit applications for string case-conversion operations using single-byte encodings like ISO-8859-1 or Windows-1252.
  • Monitor for denial-of-service activity resulting from malformed requests targeting the regular expression engine or case conversion logic.
